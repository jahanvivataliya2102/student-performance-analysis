# Student Performance Analysis

## About the Project
This is my beginner-level data analysis project using Python.
I analyzed student performance in mathematics to understand how different factors are related to final grades.

## Dataset
- Dataset: Student Performance (Mathematics)
- Total Records: 395
- Total Columns: 33
- Target Column: G3 (Final Grade)

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data inspection and exploration
- Statistical analysis
- Correlation analysis
- Data visualization
- Pass and fail analysis
- Comparison of student performance across different factors

## Key Findings
- G2 has the strongest correlation with the final grade.
- G1 also has a strong positive correlation with the final grade.
- Students with more previous failures generally have lower pass percentages.
- Some differences were observed between students with and without internet access.

## Conclusion
Previous academic performance showed the strongest relationship with final mathematics grades in this dataset.

## Limitations
The analysis is based on 395 student records. The findings do not prove cause-and-effect relationships and may not represent all students.
